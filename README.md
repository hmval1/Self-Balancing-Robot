\# Self-Balancing Robot ESP32



Proyecto final de la materia Sistemas de Control.

\## Componentes utilizados

\- ESP32

\- MPU6050

\- Driver L298N

\- Motores TT Gear Motor



\## Descripción

Este repositorio contiene los códigos utilizados para la calibración del sensor MPU6050 y el control PID del robot autoequilibrado.
